# 功能与设置

设置会即时更新应用内预览；SystemUI 的实际效果取决于模块是否激活、固件是否匹配，以及最新配置是否收到回执。预览选择不会改变手机真实电量或网络。

## 图标组成

- 外圈约 240° 圆弧表示电量，暗色底轨保留；未知电量不编造进度。
- Wi-Fi 使用三道弧线与一个点，共四层信号等级。连接正常、无互联网、需登录、连接中使用不同标记。
- Wi-Fi 未连接时，中心显示可读到的 2G/3G/4G/5G；移动数据关闭改用带斜线的上下箭头。
- 底部四点表示默认数据卡的信号，不额外显示第二组双卡信号。SIM 和飞行模式异常在此区域使用对应符号。
- 充电时闪电位于电量弧顶部，周围局部渐变虚化；充满和插电未充电分别有状态标记。
- 正常图标跟随系统颜色；电池状态色优先级为充电/充满、低电量、省电、正常。数字和中心信号不强制变成充电绿色。

## 电量数字自动显示

开启自动显示前，请关闭“始终显示电量数字”，后者优先级更高。

以阈值 30% 为例：

| 真实状态 | 显示 |
| --- | --- |
| 电量 31% | 隐藏数字 |
| 电量下降到 30% | 显示数字 |
| 电量 29% | 显示数字 |
| 插电充到 30% | 仍显示数字 |
| 电量回升到 31% | 隐藏数字，充电中恢复闪电 |

数字占据原顶部闪电的位置，不额外增加图标高度；背景虚化随数字大小变化。数字开启时替代该位置的充电/充满/暂停标记，电量弧仍保留状态色。阈值设为 100% 时，有效电量一直符合显示条件。

自动显示依据当前有效百分比计算，不需要跨重启保存“曾低于阈值”状态。真实百分比未知时不触发自动显示；充放电状态未知但百分比有效时，仍正常判断阈值。

## 诊断与恢复

- “设置已保存”只证明本机保存成功；系统回执才说明配置已被读取。
- “恢复原图标”关闭替换，不清除全部外观参数。
- 顶部“恢复默认”会重置外观参数，并关闭系统替换。
- 底部“关于”显示实际安装版本；“作者主页”通过系统打开维护者的酷安链接。
- 日志提交与故障恢复见 [安装说明](INSTALL.md) 和 [适配边界](COMPATIBILITY.md)。
