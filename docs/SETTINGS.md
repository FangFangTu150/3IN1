# 功能与设置

设置会即时更新应用内预览；SystemUI 的实际效果取决于模块是否激活、固件是否匹配，以及最新配置是否收到回执。预览选择不会改变手机真实电量或网络。

本文对应 0.1.9，包含中心电量和下拉头部覆盖。[更新说明](releases/v0.1.9.md) 与 [兼容说明](COMPATIBILITY.md) 分别列出本版功能和适用范围。

## 图标组成

- 外圈约 240° 圆弧表示电量，暗色底轨保留；未知电量不编造进度。
- Wi-Fi 使用三道弧线与一个点，共四层信号等级。连接正常、无互联网、需登录、连接中使用不同标记。
- Wi-Fi 未连接时，中心显示可读到的 2G/3G/4G/5G；移动数据关闭改用带斜线的上下箭头。
- 底部四点表示默认数据卡的信号，不额外显示第二组双卡信号。SIM 和飞行模式异常在此区域使用对应符号。
- 充电闪电和充满对勾位于电量弧顶部，周围局部渐变虚化；插电未充电保留暂停标记。
- 正常图标跟随系统颜色；电池状态色优先级为充电/充满、低电量、省电、正常。数字和中心信号不强制变成充电绿色。
- 原生 VoLTE、VoWiFi 和未注册提示保持原样，不由三合一承接。

## 电量数字中间常显

开启后，中心一直显示当前整数电量，不带百分号；电量未知显示 `?`。中心的 Wi-Fi 图形、连接与异常提示、网络制式、数据关闭箭头及占位符均不绘制。外圈电量、底部蜂窝/SIM/飞机和漫游标记仍沿用原规则；完整网络状态保留在无障碍描述中。

充电时中心数字与顶部闪电并存，充满时与顶部对勾并存，插电未充电时保留顶部暂停标记。原顶部数字不重复显示；“电量数字大小”控制中心数字，范围不变。

中间 Wi-Fi 大小、网络类型文字大小、始终显示电量数字、低于阈值自动显示、电量数字显示阈值五项统一置灰，不能修改。点击受限区域提示“已开启电量数字中间常显，请先关闭。”开关切换不覆盖这些配置，关闭后恢复原值及原互斥规则。

该模式与同一套外观设置同时应用于主状态栏、启用的锁屏状态栏及可接管的下拉头部。锁屏显示开关仅控制锁屏状态栏，不控制下拉头部。

## 电量数字自动显示

“始终显示电量数字”与“低于阈值自动显示”互斥，开启一个会自动关闭另一个，也可以全部关闭。升级时若旧配置两项都开，保留“始终显示”，关闭自动显示。无论选择哪种数字模式，充电闪电和充满对勾均优先于数字。

以阈值 30% 为例：

| 真实状态 | 显示 |
| --- | --- |
| 电量 31% | 隐藏数字 |
| 电量下降到 30% | 显示数字 |
| 电量 29% | 显示数字 |
| 插电并开始充电，电量 ≤ 30% | 显示闪电 |
| 充电至 31% | 继续显示闪电 |
| 拔线，电量仍 ≤ 30% | 恢复数字 |
| 插电但暂停充电，电量 ≤ 30% | 显示数字 |
| 已充满 | 显示顶部对勾 |

数字占据顶部标记的位置，不额外增加图标高度；背景虚化随数字大小变化。非充电、非充满时才显示数字，必要时替代暂停标记，电量弧仍保留状态色。阈值设为 100% 也不会覆盖闪电或充满对勾。切换数字模式不清除阈值、字号或颜色设置。

自动显示依据当前有效百分比计算，不需要跨重启保存“曾低于阈值”状态。真实百分比未知时不触发自动显示；充放电状态未知但百分比有效时，仍正常判断阈值。

## 诊断与恢复

- “设置已保存”只证明本机保存成功；系统回执才说明配置已被读取。
- 保存失败时保持失败提示，旧回执不会使其变为已保存。成功保存后的刷新通知不依赖设置页继续存活。
- 错误类型配置按键使用默认值，异常总开关按关闭处理，其他正常参数保留；仍可使用恢复原图标和恢复默认。
- “恢复原图标”关闭替换，不清除全部外观参数。
- 顶部“恢复默认”会重置外观参数，并关闭系统替换。
- 底部“关于”显示实际安装版本；“作者主页”通过系统打开维护者的酷安链接。
- 日志提交与故障恢复见 [安装说明](INSTALL.md) 和 [适配边界](COMPATIBILITY.md)。
