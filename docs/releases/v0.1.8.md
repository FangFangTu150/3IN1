# 3IN1 0.1.8 compat

**发布类型：Pre-release（预发布）**

[项目源码](https://github.com/FangFangTu150/3IN1) · [下载入口](https://github.com/FangFangTu150/3IN1/releases/tag/v0.1.8)

2026-09-23，versionCode 9。本版本已完成本地构建、Lint 与单元测试；真机 ART/LSPosed 验收待完成。

## 更新

- 充电中优先显示闪电，充满优先显示顶部对勾，不再被常显或低电量自动数字覆盖。
- 非充电、非充满时按数字设置显示；暂停充电不伪装为正在充电，拔线后立即按有效电量判断。
- 常显和自动数字开关双向互斥，一次保存两个值；允许全部关闭。旧冲突配置保留常显，读取端同步兜底。
- 充满对勾移到闪电所在的顶部区域，并复用仅作用于圆弧的渐变虚化，不影响背景和网络信号。
- 保留当前运行时兼容性校验与失败回退，不恢复精确型号限制。本版不增加快充协议或紫色闪电。
- 诊断刷新使用唯一探测令牌和独立回执快照，只将当前请求对应的 SystemUI 回执标记为已接收。
- 绘制时保留 SystemUI 原始 tint alpha，避免半透明状态栏下图标被意外绘制为不透明。
