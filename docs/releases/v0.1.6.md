## 0.1.6 更新

1. 新增机型判断适配优化，解决部分设备反馈不生效的问题；一加 13 真机验证通过。
2. 放开精确型号、固件构建号和 SystemUI 版本判断，保留运行时反射校验和异常回退。
3. Wi-Fi 只查询当前 Wi-Fi Network capabilities，避免把蜂窝验证当成 Wi-Fi 已联网。
4. 修复非 active 宿主错误更新辅助功能描述的问题，并恢复原生描述和重要性。
5. 刷新广播使用 signature permission，并合并重复刷新请求。

## 0.1.5 更新

- 修复充放电状态为 UNKNOWN 时有效电量百分比被丢弃的问题。
- 消费初始 sticky 电量，只记录变化的电量快照。
- 关于入口读取运行时版本，并支持打开作者主页。

## 兼容性与验证

- 项目仅基于 ColorOS 16 / Android 16 / API 36 开发，其他 Android/ColorOS 版本不作保证。
- 一加 13 / `PJZ110` / `PJZ110_16.0.10.501(CN01)` 已通过真机验证。
- 其他 ColorOS 16 机型仍需自行验收；需要 Root/LSPosed，作用域仅选择 `com.android.systemui`。
- 本地构建、Lint 和 55 项 JUnit/Robolectric 测试通过；本地测试不能替代真实 ART/Xposed hook 验收。
- 只覆盖状态栏和锁屏，不修改 QS/AOD。

## 安装者须知

需要 Root/LSPosed 或兼容框架；只选择 `com.android.systemui` 作用域，不要选择 Android Framework 或所有应用。安装、更新和恢复见 [安装文档](https://github.com/FangFangTu150/3IN1/blob/main/docs/INSTALL.md)。

`compat` 为非 debug APK，但使用现有 debug/test 签名以兼容已有测试安装；签名密钥不发布，更新必须保持相同签名。SystemUI 异常时先在 LSPosed 停用模块，再按现有 Root/LSPosed 恢复流程重启。

## 发布内容

版本标签为 `v0.1.6`，附上 compat APK 和 SHA-256。项目仅基于 ColorOS 16 开发，不宣称全机型支持。
