## 变更

### 0.1.5 电量未知修复

有效 level/scale/present 百分比独立于充放电 status 解析。status 为 UNKNOWN 时仍可驱动进度、低电量颜色和低阈值自动数字显示，但不会伪造充电、充满或暂停；消费初始 sticky 电量，只记录变化的电量快照；关于入口读取安装版本并在用户点击后打开作者主页。

### 0.1.6 三个 P2 修复

1. Wi-Fi 只查询当前 Wi-Fi Network capabilities，避免把蜂窝验证当成 Wi-Fi 已联网；capabilities 暂缺时显示连接中。
2. 辅助功能描述只在替换 active 时接管，释放时恢复最新原生描述和重要性，包括 null；未激活宿主不改写。
3. 刷新广播使用 signature permission；合并刷新请求不推迟首次 deadline，执行期间请求安排一次后续刷新。
4. 新增机型判断适配优化，解决部分反馈不生效的问题；一加 13 真机验证通过。

## 验证与限制

- 本地构建、Lint 和 55 项 JUnit/Robolectric 测试通过。
- 0.1.1 用户截图证明目标设备曾实际替换，但出现 tint/spacing 问题。
- 一加 13 真机验证已通过，但不能据此宣传全机型支持；其他 ColorOS 16 机型仍需单独验收。
- 本地测试不执行真实 ART/Xposed hook，不能替代锁屏、重启、网络切换、SystemUI 崩溃恢复和辅助功能真机检查。
- 只覆盖状态栏和锁屏，不改 QS/AOD；继承父级防烧屏移动但不保证 OLED 不老化。

## 安装者须知

需要 Root/LSPosed 或兼容框架；只选择 `com.android.systemui` 作用域，不要选择 Android Framework 或所有应用。安装、更新和恢复见 [安装文档](https://github.com/FangFangTu150/3IN1/blob/main/docs/INSTALL.md)。

`compat` 为非 debug APK，但使用现有 debug/test 签名以兼容已有测试安装；签名密钥不发布，更新必须保持相同签名。SystemUI 异常时先在 LSPosed 停用模块，再按现有 Root/LSPosed 恢复流程重启。
